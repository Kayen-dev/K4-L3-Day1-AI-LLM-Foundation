    Talk track

    5 minute presentation flow

    1. Start from config: API key lives in .env, model names can be swapped without code edits.
    2. Show system prompt versus user prompt, then explain the exact message stack sent to the model.
    3. Move temperature and top-p once, explain that both affect sampling, but experiments should isolate one variable.
    4. Click Stream reply and point out time-to-first-text, running token count, cost and 3-turn history.
    5. Click Compare models and discuss quality, latency and cost tradeoff for product decisions.
